# 🎮 Tic Tac Toe

A simple and responsive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.  
This project allows two players to take turns playing directly in the browser, with automatic detection of winners and draws.

---

## 🧩 Features

- ✅ Two-player local gameplay (X and O)
- 🎯 Automatic winner and draw detection
- 🔁 Restart button to reset the game
- 🎨 Clean and minimal design
- ⚡ No external libraries — pure HTML, CSS, and JavaScript

---

## 🚀 Demo

You can open the game by simply running the `index.html` file in your browser.

```bash
# Clone this repository
git clone https://github.com/yourusername/tic-tac-toe.git

# Navigate to the project folder
cd tic-tac-toe

# Open the game in your browser
start index.html
```

## 🧠 How to Play

The game randomly selects who starts (X or O).

Players take turns clicking on an empty square.

The first player to align three symbols horizontally, vertically, or diagonally wins.

If all squares are filled and no one wins, the game ends in a draw.

Click Reset to start a new match.
